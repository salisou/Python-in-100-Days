# Guida completa dei 100 giorni

## Metodo didattico

Ogni giornata segue: obiettivo, teoria, sintassi, esempio semplice, esempio realistico, spiegazione riga per riga, errori comuni, esercizio guidato, soluzione, esercizio autonomo e riepilogo.

## Percorso

- Giorni 1-21: fondamenti, strutture dati, file e dati.
- Giorni 22-28: programmazione orientata agli oggetti.
- Giorni 29-35: GUI con Tkinter.
- Giorni 36-42: sviluppo web con Flask.
- Giorni 43-50: NumPy, Pandas, pulizia, analisi e visualizzazione.
- Giorni 51-60: progetti applicativi.
- Giorni 61-70: API, automazione, logging, testing e qualità.
- Giorni 71-80: AI e Machine Learning.
- Giorni 81-90: AI applicativa, sicurezza, performance, asyncio e database.
- Giorni 91-100: SQL, ORM, architettura, API professionali, testing, deployment e progetto finale.

## Lingua

Commenti, spiegazioni e messaggi rivolti allo studente sono in italiano. La sintassi Python non viene tradotta.

## Riferimento

La sintassi e i concetti fondamentali sono coerenti con la documentazione ufficiale Python 3.12. Il materiale è adattato a un percorso progressivo e pratico.
