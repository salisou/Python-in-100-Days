# Python-in-100-Days

## Corso di Python in 100 giorni

Repository didattico di **Docente Moussa Salisou**. Il percorso è pensato per accompagnare lo studente dai fondamenti di Python fino alla programmazione orientata agli oggetti, alle GUI, allo sviluppo web, alla Data Science e ai primi progetti di AI e Machine Learning.

> **Stato del repository:** il materiale attualmente presente copre le giornate disponibili fino al **Day 80**. La struttura è organizzata per proseguire il percorso fino al Day 100 senza cambiare il metodo didattico.

## Percorso

1. **Base** — sintassi, variabili, tipi di dati, operatori, condizioni, cicli e funzioni.
2. **Intermedio** — file, strutture dati, moduli ed eccezioni.
3. **Lavoro con i dati** — gestione e analisi dei dati.
4. **OOP** — classi, oggetti, attributi, metodi ed ereditarietà.
5. **GUI** — applicazioni desktop con Tkinter.
6. **Sviluppo web** — applicazioni web con Python e Flask.
7. **Python Data Science** — NumPy, Pandas, Matplotlib e analisi dei dati.
8. **Progetti intermedi** — applicazioni per consolidare le competenze.
9. **Progetti intermedi avanzati** — API, automazione, dati e applicazioni reali.
10. **AI e Machine Learning** — progetti applicativi.

## Metodo didattico

Ogni giornata deve contenere, quando pertinente:

- spiegazione teorica in italiano;
- codice commentato;
- esempio pratico;
- output atteso;
- esercizio guidato;
- esercizio autonomo;
- soluzione;
- riepilogo;
- errori comuni e correzioni.

Il corso è stato uniformato per essere utilizzabile come materiale didattico reale, non come semplice raccolta di script.

## Lingua

Commenti, spiegazioni e messaggi mostrati allo studente sono in **italiano**.

La sintassi Python resta invariata: `print`, `input`, `if`, `for`, `while`, `def`, `class`, `import` e gli altri elementi del linguaggio non vengono tradotti.

## Pulizia dei materiali

Sono stati rimossi dagli script i riferimenti automatici provenienti da notebook Google Colab, compresi:
